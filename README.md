# رفيق | Rafiq AI

مساعد جامعي ذكي يقرأ مستنداتك (PDF) ويجيب عن أسئلتك **من محتواها فقط**، مع ذكر رقم الصفحة اللي استند عليها.

🔗 **التطبيق المنشور:** https://rafiq-ai-6ezvxqzsq67gjstvk6qbsc.streamlit.app

## الفكرة
الطالب يضيع وقت وهو يدور في ملفات طويلة (لوائح، محاضرات، أدلة). رفيق يخلّيه يرفع الملف ويسأل بالعربي، ويجاوبه من الملف نفسه بدون اختلاق.

## كيف يشتغل (RAG)
1. **قراءة الملف:** استخراج النص من الـPDF صفحة صفحة (PyMuPDF).
2. **التقطيع:** تقسيم النص لمقاطع متداخلة عشان ما يضيع المعنى بين مقطع ومقطع.
3. **Embeddings:** تحويل كل مقطع لمتجه يمثّل معناه، بنموذج يدعم العربية والإنجليزية.
4. **التخزين والبحث:** حفظ المتجهات في ChromaDB، وجلب أقرب المقاطع للسؤال.
5. **الإجابة:** إرسال المقاطع المناسبة فقط إلى Gemini، فيجاوب منها ويذكر رقم الصفحة.
